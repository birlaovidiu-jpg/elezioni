# Elezioni

Programma di votazione segreta per le chiese e per l'assemblea dei delegati.

- **Chi vota:** inquadra il QR code del segretario → `index.html?s=CODICE`
- **Segretario:** `segretario.html`

I voti passano da Firebase (progetto `elezioni-sdarm`); le regole di sicurezza sono in `firestore.rules`.
